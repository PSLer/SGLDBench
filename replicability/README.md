# 3. How to Reproduce the Representative Image (Fig. 1a in the paper)

Steps:
- Install MATLAB (R2022b or newer is recommended) with its `Image Processing Toolbox` and `Parallel Computing Toolbox` on Windows.
- Open MATLAB and nevigate to the directory `./SGLDBench/replicability/` and find the MATLAB script `QuickAccess_Mtd1_TopOpti_replicate_Fig1a.m` in this folder.
- Run `QuickAccess_Mtd1_TopOpti_replicate_Fig1a.m` (a system with at least 16GB RAM is necessary).
- Wait for the script to finish. This can take a long time depending on the used hardware. For reference, it in our tests it took 1.5 hours on a 6 core Intel Xeon-W2235 processor.
- Open the web renderer (quokka) from the link https://keksboter.github.io/quokka/.
- Open the file `./SGLDBench/out/ResultVolume_Design.nii` generated by this script in quokka. 
- The custom RGB color used in the image is (255, 240, 214).
